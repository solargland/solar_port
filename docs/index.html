🐾 零基础小白桌宠制作指南

没有深奥的底层大道理，不讲复杂的学术名词！用最直白的人话，带你一步步弄懂电脑桌面上那只蹦蹦跳跳的小宠物是怎么做出来的。

通俗好懂 只需一个 C# 文件 双击就能玩 换图即换皮
💡

1分钟看懂桌宠原理

其实它跟普通软件没太大区别，只是玩了几个视觉魔术
💡 通俗打个比方：
平常我们打开浏览器或微信，都有一个白底的方框框对吧？桌面小宠物，其实就是拿了一张透明的塑料纸当窗口，把白色的背景擦掉，在塑料纸正中间放一张透明底的小猫图片。因为塑料纸是透明的，所以你眼里只能看到这只悬浮在桌面上的小猫！

整只桌宠一共就负责这 4 件事：

  1. 隐形窗口：把自带的白色框框和叉叉隐藏掉，整个窗体全透明。
  2. 像翻连环画一样动：每隔 0.1 秒换下一张图，连起来小动物就在呼吸、眨眼。
  3. 跟着鼠标跑：鼠标按住小猫时，小猫跟着鼠标坐标移动，抓起来还会换成“被拎起来”的挣扎图片。
  4. 右下角小图标：在电脑右下角（时钟旁边）放个小图标，方便你随时关掉它或者重新叫出来。
📦

第1步：准备工程文件

告诉电脑我们要做的是一个 Windows 程序
👉 人话解释：新建一个 DesktopPet.csproj 文件，就像给电脑一张清单，告诉它：“我要做个 Windows 桌面应用，请把画界面的画笔和右下角托盘的功能借给我用！”
DesktopPet.csproj 
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <!-- 生成桌面窗口程序，不要弹出黑色的命令行黑框框 -->
    <OutputType>WinExe</OutputType>
    <TargetFramework>net8.0-windows</TargetFramework>
    
    <!-- 借用 WPF 的画笔（用来画透明窗口和放图片） -->
    <UseWPF>true</UseWPF>
    
    <!-- 借用 WinForms 的托盘能力（用来在右下角放小图标） -->
    <UseWindowsForms>true</UseWindowsForms>
  </PropertyGroup>

  <!-- 自动把 assets 文件夹里的图片打包带上 -->
  <ItemGroup>
    <Content Include="assets\**\*.*" CopyToOutputDirectory="PreserveNewest" />
  </ItemGroup>
</Project>

第2步：做个透明隐形窗口

拆掉白色的方框，让桌宠像漂在桌面上一样
👉 人话解释：普通的软件都有标题栏、最小化、关闭按钮，背景也是白的。我们需要把这些统统关掉，换成“隐形玻璃”。
给窗口设置的 5 个关键开关 
// 1. 把窗户四周的边框和顶上的标题栏全部扔掉
WindowStyle = WindowStyle.None;

// 2. 开启“隐形玻璃”模式（允许透明）
AllowsTransparency = true;

// 3. 把默认的白底背景改成完全透明
Background = Brushes.Transparent;

// 4. 永远置顶！这样就算你打开网页或打游戏，小宠物依然坐在最前排
Topmost = true;

// 5. 不要在屏幕底下的任务栏里占一个长条格子（只留在右下角小托盘就行）
ShowInTaskbar = false;

就这短短 5 句话，一个“隐形悬浮窗口”就做好了！此时窗口里放什么，桌面上就只看得见什么。

第3步：鼠标抓着走与防掉出屏幕

鼠标按住小宠物就能拽着到处跑，而且不会甩丢
👉 人话解释：小动物不能呆呆地死在一处，得能用鼠标挪位置。而且要加上“防掉落护栏”，防止你手一抖把它甩到屏幕外面找不回来了。

实现分三小步：

  • 鼠标按下去时：记录小宠物当前位置，抓住鼠标焦点（CaptureMouse()，防止手滑滑太快断掉）。
  • 鼠标拖动时：鼠标移动了多少距离，小宠物的坐标就跟着加多少距离。
  • 电子围栏（防出界）：每次移动都检查一下，如果坐标小于 0（出了左边）就按在边缘；如果坐标大于屏幕宽度（出了右边）也按在边缘。
简化的防出界代码（电子围栏） 
private void ClampToScreen()
{
    // 保证 X 坐标：最小是 0（不超左边），最大是 屏幕宽减去小猫宽（不超右边）
    Left = Math.Max(0, Math.Min(Left, 屏幕宽度 - Width));
    
    // 保证 Y 坐标：最小是 0（不超顶部），最大是 屏幕高减去小猫高（不超底部）
    Top = Math.Max(0, Math.Min(Top, 屏幕高度 - Height));
}

第4步：放图片让小宠物动起来

像翻动小人书一样，连续切换图片产生动画效果
👉 人话解释：动画其实是骗眼睛的！我们准备几张动作连贯的图片（比如小猫睁眼、闭眼、尾巴晃动），设定一个小闹钟，每隔 0.1 秒换下一张图片贴上去，小动物看起来就像是活的一样！

在项目中我们准备了两个动作小分组：

  • assets/idle/ 目录：放待机动作（平时小宠物趴在桌上发呆的连环画）。
  • assets/drag/ 目录：放被抓起动作（鼠标按住拖拽时，立刻换成手忙脚乱的动作）。
动画切换原理 
// 设定一个小闹钟（每隔 50 毫秒响一次）
_timer = new DispatcherTimer { Interval = TimeSpan.FromMilliseconds(50) };
_timer.Tick += (s, e) => 
{
    // 如果鼠标正在抓它，就放抓取的连环画；如果平时发呆，就播放待机连环画
    var 当前图集 = 正在拖拽 ? 抓起动画组 : 待机动画组;
    当前显示第几张 = (当前显示第几张 + 1) % 当前图集.Length;
    
    // 重新刷新屏幕上的图像
    InvalidateVisual();
};
_timer.Start();

第5步：右下角托盘图标控制

像微信、QQ 一样，在电脑右下角放一个小图标
👉 人话解释：平时桌宠漂在屏幕上，如果你想让它暂时退下，或者彻底退出程序，最符合习惯的办法就是在右下角时钟边上常驻一个图标。
  • 鼠标双击托盘图标：把可能藏在某个窗口后面的桌宠重新唤醒置顶。
  • 鼠标右键托盘图标：弹出菜单，可以选择“显示桌宠”或“退出程序”。

第6步：右键调大小与透明度

右键点击桌宠弹出一个可爱的小菜单
👉 人话解释：有的人屏幕大觉得桌宠太小，有的人觉得挡视线想调半透明。我们在桌宠身上监听鼠标右键，一点右键就弹出一个无边框的设置小卡片。

菜单里提供了三个非常直观的拖动滑块：

  1. 透明度滑块：拉到左边若隐若现（20%），拉到右边完全不透明（100%）。
  2. 播放速度滑块：可以让它慢悠悠地发呆（0.5x），也可以让它像疯了一样快动（2.0x）。
  3. 体型大小滑块：直接改变窗口宽度和高度，小动物就会等比例变大或变小。
贴心小设计：当你调完之后，只要在桌面空白处点一下，这个设置菜单就会自动悄悄关闭，完全不打扰你。

第7步：让它记住你上次放的位置

关机重开后，小宠物依然乖乖待在上次那个角落
👉 人话解释：如果每次开电脑，桌宠都重置到左上角，大小透明度都要重新调，那就太烦了！所以每次关掉前，它会悄悄在你的电脑里写个小记事本（settings.json）。

记事本里就记着这几行字：

%LOCALAPPDATA%\DesktopPet\settings.json 
{
  "Opacity": 1.0,         // 透明度：100%
  "PlaybackSpeed": 1.3,   // 速度：1.3倍速
  "Size": 0.8,            // 大小：80%
  "Left": 935,            // 横坐标：在屏幕横向 935 像素处
  "Top": 140              // 纵坐标：在屏幕纵向 140 像素处
}

下次再打开它时，先看一眼记事本，直接把小宠物放到上次的坐标上去！

第8步：一键运行起来！

不需要装臃肿的开发软件，直接双击运行
👉 人话解释：很多小白学编程最头疼的就是“配置开发环境、下载好几个 G 的大软件”。这个项目最大的好处之一就是已经把成品编译好了！

怎么玩它？

  1. 直接打开 D:\to_project2\desktop-pet\bin\DesktopPet.exe，双击它！
  2. 你的屏幕上就会立刻跳出这只小宠物。
  3. 用鼠标左键拖它，右键调大小，右下角托盘随时可以关掉它。

新手动手玩：怎么换成我自己喜欢的角色？

无需改任何代码，只换图片就能给桌宠“换皮”！

这是最适合新手折腾的地方！只要你把图片名字按规则命名，程序就会自动读取：

  1. 找到你的图片，必须是背景透明的 PNG 格式（白底的不行，会挡住桌面）。
  2. 准备待机动作：放入 assets/idle/ 文件夹，名字叫 idle-1.png, idle-2.png。
  3. 准备拖拽动作：放入 assets/drag/ 文件夹，名字叫 drag-1.png, drag-2.png。
  4. 再次打开程序，小宠物就瞬间变成你换上的新角色啦！
小妙招：如果你在网上看到一个喜欢的 GIF 动图，可以搜“GIF 在线逐帧拆分”，把动图拆成一帧帧透明 PNG，按序号排好放进去就行！

新手最常问的 4 个问题

踩坑排错手册
Q1：为什么我换了自己的图片后，小宠物身上有难看的白色方框底色？
答：因为你的图片不是“透明底 PNG”。如果是白底 JPG，程序会把白色也画在桌面上。可以用手机或网页抠图工具把背景扣掉，存成透明 PNG 即可。
Q2：如果不小心把小宠物拖到了屏幕外面，看不到了怎么办？
答：别慌！直接在电脑右下角托盘图标上双击，或者关掉后在记事本里把 settings.json 中的 Left 和 Top 改成 100，它就回到屏幕左上方了。
Q3：它会占用很多电脑内存或卡电脑吗？
答：完全不会！这个项目只有 1 个文件，不加载任何乱七八糟的外部库，运行时内存占用仅二三十兆，比打开一个网页还要轻巧得多。
Q4：我想修改动作播放得再慢一点怎么办？
答：最简单的方法是右键点击桌宠，把“播放速度”滑块往左拉；或者在代码里把每隔 50ms 触发的闹钟改成 100ms 即可。
